# Megascans, collections and Fab Web {#megascans-collections-and-fab-web}

Three sources must not be confused: the historical Quixel/Megascans account, Megascans products in the direct Fab library, and Megascans via Fab's official website connector. Their sessions, caches and acquisition paths are not interchangeable.

## Historical library and collections {#historical-library-and-collections}

Choose Library → Megascans and connect the historical account when that service accepts it. Browse assets or official collection metadata. A collection page describes a themed set; public metadata and covers do not grant ownership or download rights. Select assets and formats only when your account is entitled to them.

Cached catalogs can remain available offline; an unavailable legacy login does not imply that your historical files were deleted. Register or inspect existing local content without replacing the original cache. RAW geometry, textures and native Unreal packages require different installation scripts.

## Megascans via Fab {#megascans-via-fab}

Use the dedicated connector to open the official Fab catalog/library and sign in on that site. A seller catalog can contain products you do not own. Downloads and acquisitions remain subject to the site's controls and licenses; the hub does not automate purchases or mass ownership claims.

For native acquired-item sheets, open Connection / Synchronize Fab, sign in, then Synchronize Megascans sheets. Return through Native sheets / MCP. Synchronization imports acquired Quixel Megascans entries; bulk-claimed items absent from the acquired library are not a complete synchronized entitlement inventory. Cancellation/error preserves the previous cache.

Downloading such a sheet opens its official Fab page for file selection and confirmation. Direct installation is unavailable without a real native variant. Completed web files appear under downloaded files and are not automatically linked to their parent product. This is not a universal native RAW-download API or a repaired historical Quixel login. Missing site metadata remains explicit.

Configure this connector's own download folder and library under Marketplaces. A downloaded file can then be packaged, classified and passed to the appropriate [installation](doc:install) or [source-conversion](doc:conversion) workflow. Do not assume a texture ZIP is already a .uasset pack.

If legacy authentication fails, use authorized existing downloads or the official Fab route your account supports. Do not copy cookies or private API keys into a shared configuration. See [Fab](doc:fab), [connectors](doc:connectors) and [settings](doc:settings).
