# README screenshots

Real CyEngineHub desktop captures from the local `2.0.0-alpha.41` development
build, rendered at 1280 × 820 with the default mid-grey theme. This is a preview,
not a claim that this UI is already in the latest GitHub release.

- `engines.png`: three fictional Unreal installations.
- `project-creation.png`: the actual C++/Blueprint project creation form.
- `source-conversion.png`: Blender conversion options and optional Unreal import.

All data is synthetic. The displayed `D:\Engines` and `D:\Projects` locations are
demo labels, not user installations. No account was connected, no project created
and no converter executed to make these captures. No asset-provider artwork or
private library content is included. Images are unretouched application captures.

The local UI QA harness can regenerate them with `--readme-screenshots`.
