# CyEngineHub V2 — alpha.34

Cette version ajoute le plugin **CyEngineHub dans Unreal Editor · Alpha**.
Sauvegardez vos projets et terminez les opérations en cours avant la mise à jour.
Le badge Latest désigne la release courante, pas une garantie de stabilité.

## Bibliothèque dans Unreal

- Nouveau panneau natif Slate : **Fenêtre → CyEngineHub · Alpha**.
- Recherche dans la bibliothèque possédée et les collections, pagination et choix
  d’une variante compatible avec le moteur du projet ouvert.
- Installation confirmée dans ce projet via les téléchargements, caches,
  bibliothèques et tâches existants du Hub.
- Suivi des tâches avec barres colorées ; actualisation du registre des assets
  après import de contenu. Les nouveaux plugins nécessitent un redémarrage d’Unreal.
- **Options dans le Hub…** prépare la fiche et ses options avancées sans lancer
  d’installation.

## Installation du plugin et sécurité

- Bouton **Installer le plugin éditeur…** dans la fiche moteur, avec confirmation
  du chemin. Compilation contre ce moteur, puis publication du seul plugin dans
  `Engine/Plugins/Marketplace/CyEngineHub` ; temporaires de compilation nettoyés.
- Activation par défaut pour les projets qui ne désactivent pas explicitement le
  plugin ou tous les plugins moteur par défaut. Module Editor uniquement : aucun
  module de ce plugin dans les jeux packagés.
- Connexion locale réservée au compte Windows courant, indépendante de l’IA/MCP.
  Aucun port HTTP, achat, secret marketplace ou commande arbitraire exposé.
- Le projet doit être enregistré dans le Hub avec une association moteur correcte.
  Les demandes sans confirmation, incompatibles ou destinées à un projet inconnu
  sont refusées. Un identifiant de demande évite une double installation en session.
- Imports en éditeur strictement additifs : aucun asset ou plugin existant remplacé,
  y compris si un conflit apparaît après l’analyse. Les scripts avancés enregistrés
  ne sont ni hérités ni modifiés par l’action d’import direct.

## Compatibilité et limites Alpha

Sources prévues pour **UE 4.27 et 5.0 à 5.8 sous Windows**. Compilation vérifiée
sur 4.27.2, 5.2.1, 5.3.2, 5.4.4, 5.5.4, 5.6.1, 5.7.4 et 5.8.3.
**5.0 et 5.1 restent non vérifiés** : aucun binaire n’est publié pour ces deux versions.

Le parcours natif complet a été testé sous 4.27.2 et 5.8.3, avec le vrai backend
desktop, un téléchargement synthétique et un projet jetable : panneau Slate,
connexion C++/.NET, recherche, confirmation, création de tâche, déduplication,
fin d’import et vérification des fichiers. Les autres versions ont une validation
de compilation, pas encore une validation fonctionnelle complète.

L’import direct concerne les packs Fab Unreal compatibles et les plugins de projet.
Les conversions, déplacements, imports RAW, chaînes de scripts, groupes et fonctions
spécifiques aux connecteurs restent des workflows du Hub, éditeur fermé si nécessaire.
Les galeries et tous les écrans du Hub ne sont pas intégrés au panneau Unreal.

- Installateur Windows x64 et ZIP autonome, avec conservation des données utilisateur.
- Huit ZIP de plugin séparés, avec DLL et manifeste de module pour les builds
