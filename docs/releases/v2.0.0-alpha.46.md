# CyEngineHub 2.0.0-alpha.46

[English](v2.0.0-alpha.46.en.md) · [Téléchargements Windows](https://github.com/MrMybal/CyEngineHub/releases/tag/v2.0.0-alpha.46)

## Assistant et commandes MCP

- **Paramètres → IA / MCP** ouvre l’assistant intégré. Il affiche les réponses au fil de leur génération et permet de les annuler, de joindre des fichiers et de restaurer l’historique. La taille du contexte envoyé au fournisseur est réglable.
- Le chat, le CLI et les clients MCP externes partagent les dix opérations métier et les règles de confirmation du hub. Le CLI propose `list`, `describe` et `call`, avec sortie JSON. Le chat peut aussi appeler les outils autorisés d’un serveur MCP HTTP(S).
- Le compagnon de réparation Unreal utilise CyMCPSDK 0.7.0 à la révision `ced8296b555c1969cb29740eba65beaa0687da7d`. Les copies de réparation, les jobs et leurs résultats historiques restent utilisables. [Configuration, commandes et périmètre MCP](../ai-mcp.md)

## Bibliothèque et projets Unreal

- La fiche Fab affiche séparément le transfert, la reconstruction, l’archivage et le stockage. La reconstruction réutilise les blocs décompressés et vérifie les fichiers pendant leur écriture.
- Un déplacement entre disques publie le package complet avant de nettoyer la source. Safe Clean et la création des ZIP contrôlent les jonctions Windows. Les importations locales conservent leur package après le nettoyage du dossier temporaire.
- Les règles des projets C++ générés s’adaptent à la version Unreal. L’installation de plugins conserve leurs bibliothèques d’exécution tierces, et la découverte écarte les sauvegardes.

Les binaires de cette version ciblent Windows x64. Les plugins éditeur précompilés restent disponibles dans la [version alpha.45](https://github.com/MrMybal/CyEngineHub/releases/tag/v2.0.0-alpha.45). Leur compatibilité dépend du build Unreal utilisé.
