# CyEngineHub 2.0.0-alpha.35

Build local Windows. Cette version n’est pas encore publiée sur GitHub.

- Toutes les variantes Fab restent visibles et sélectionnables, même sans
  correspondance de version déclarée. La compatibilité est une indication ; les
  scripts conservent leurs contrôles de plateforme, de contenu et d’installation.
- Changer de projet ou de script ne supprime plus les choix manuels de variantes.
- Le bouton « Retour aux assets » ferme la fiche et retrouve le catalogue avec
  sa recherche et sa page, y compris après une actualisation liée à l’installation.
- Le doublon de bouton Retour dans la fiche a été retiré. Les contrôles stricts
  du plugin éditeur Unreal sont conservés.
- La GPLv3 du Hub et les notices MIT séparées de notre code natif Unreal sont
  incluses dans les paquets Windows et conservées à l’installation des plugins.

Sauvegardez vos projets avant un import ou une conversion. Un choix manuel hors
version déclarée ne convertit pas les assets : un downgrade peut exiger le script
de conversion. Les limitations Alpha des convertisseurs restent applicables.
