# CyEngineHub 0.1.0-alpha.3

Nouvelle Alpha Windows x64, reconstruite depuis l'historique nettoyé.

## Confidentialité

- Aucune clé Algolia Quixel fournie ou extraite automatiquement depuis Bridge.
- La configuration locale facultative `CYENGINEHUB_QUIXEL_ALGOLIA_KEY` est conservée,
  uniquement pour une clé dont l'utilisation a été autorisée. Sans elle, les
  recherches historiques Megascans concernées restent désactivées avec un message.
- Contrôles de confidentialité sur les sources et les fichiers de distribution.
- Aucun compte, cookie, inventaire personnel, cache de session ou bibliothèque
  d'assets n'est fourni. Aucun ancien binaire des releases retirées n'est réutilisé.

## Changements inclus

- File persistante des téléchargements natifs de bibliothèque, reprise et nombre
  de transferts simultanés réglable ; statistiques de progression et de vitesse.
- Protection contre les lancements multiples du hub.
- MCP : propositions et lots de téléchargements non bloquants, limites et
  autorisations configurables, consultation du catalogue en cache.
- Paramètres de stockage par marketplace et améliorations de leur sauvegarde.
- Navigateur intégré pour les connecteurs web, fiches des téléchargements locaux,
  variantes dérivées et espaces temporaires de test/édition des packs.
- Validations supplémentaires des installations Unreal, déplacements de contenu
  et conversions expérimentales entre versions/moteurs.

## Installation et limites

Utilisez `CyEngineHub-0.1.0-alpha.3-Setup-win-x64.exe`, ou extrayez entièrement le
ZIP et lancez `CyEngineHub.Desktop.exe`. Le runtime .NET est inclus. Les empreintes
des téléchargements figurent dans `SHA256SUMS.txt`.

**Cette application reste une Alpha : des fonctions sont incomplètes ou instables,
et beaucoup de tests réels restent nécessaires. Sauvegardez vos projets.**

- L'accès historique Megascans/Algolia n'est pas rétabli par cette version.
- Les binaires ne sont pas signés Authenticode ; Windows peut afficher un avertissement.
- Le navigateur Windows nécessite Microsoft Edge WebView2 ; la connexion Fab manuelle reste disponible.
- Les adaptateurs Unreal natifs spécifiques à une installation moteur ne sont pas
  distribués précompilés. Leur source est fournie ; leur absence bloque les opérations
  qui les nécessitent. Les conversions ne sont pas un downgrade universel.
- Aucun moteur Unreal ni asset tiers n'est distribué.
- Fermez complètement toute ancienne version avant de lancer celle-ci : les anciens
  exécutables ne participent pas à la protection contre les instances multiples.

Ne joignez jamais de jeton, cookie, configuration privée ou inventaire personnel
aux rapports de bugs.
