# 2.0.0-alpha.38 — Modular CyUI (local build)

Desktop UI migration to pinned CyUI Core, DocumentViews, Diagnostics, Inspector
and Images. Canvas/Code are automatic dependencies; unrelated modules are disabled.
The former ImGui.NET 1.91 dependency, local palette/font setup, rich-description
renderer, progress drawing and enlarged-gallery navigation renderer are replaced.

One shared native ImGui 1.92.1 runtime serves CyUI and Hexa.NET.ImGui 2.2.8.5.
The renderer supports its dynamic font atlas lifecycle. Five CyUI themes and two
densities are available, with persisted appearance/component-locale preferences.
Inspector drafts commit through existing host setters and support text Undo/Redo
and Escape cancellation before closing a parent modal. Build/Git/raw logs use
bounded Diagnostics buffers, while raw file persistence stays in the Hub.

Existing catalogue paging, Windows pickers, WebView2 sign-in, safe HTML conversion,
asset validation, source selection, parallel installation and application data remain
host-owned. The Unreal 4.27–5.8 Slate plugin is deliberately retained because the
current official CyUI Unreal connector starts at 5.5.

See [the integration guide](../cyui-migration.md) for exact revisions, licensing,
build/test commands and remaining module/OS limits. Windows x64 is tested;
Linux/macOS and monitor-DPI switching have not been validated here.

This is a local build. No commit, push, tag or GitHub Release is created by this migration.
