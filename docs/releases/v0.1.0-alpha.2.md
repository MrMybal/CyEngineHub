# CyEngineHub 0.1.0-alpha.2

Deuxième Alpha publique Windows x64.

## Nouveautés

- Connexion Fab dans une fenêtre Epic intégrée à l'application sous Windows.
- Récupération automatique de la réponse d'autorisation, sans copier le code JSON.
- Mode de connexion manuel conservé comme solution de secours.
- Nouvel onglet Collections Megascans avec les sélections officielles Quixel.
- Recherche des collections, couvertures asynchrones, cache local et fonctionnement hors ligne.
- Ouverture d'une collection limitée aux assets réellement présents dans la bibliothèque du compte.
- Affichage virtualisé afin de ne construire que les cartes visibles.

## Installation

Utilisez `CyEngineHub-0.1.0-alpha.2-Setup-win-x64.exe`, ou extrayez entièrement le ZIP
puis lancez `CyEngineHub.Desktop.exe`. Le runtime .NET est fourni.
Les empreintes sont disponibles dans `SHA256SUMS.txt`.

## À savoir avant de tester

- Cette version reste une Alpha : de nombreuses fonctions sont incomplètes ou instables et il manque encore beaucoup de tests en conditions réelles.
- Sauvegardez vos projets avant toute installation, conversion ou modification.
- Les binaires ne sont pas signés Authenticode ; Windows peut donc afficher un avertissement.
- Le mode automatique Fab nécessite le runtime Microsoft Edge WebView2. Le mode manuel reste disponible.
- Les connecteurs Fab/Quixel communautaires peuvent évoluer ; un compte autorisé est requis.
- Unity Asset Store ne possède pas encore de connecteur distant complet.
- La conversion Unreal entre versions demeure expérimentale et ne couvre pas tous les assets, Blueprints, plugins ou matériaux.
- Aucun moteur ni asset tiers n'est distribué avec l'application.

Pour signaler un problème, créez une issue en précisant la version, les étapes de reproduction
et un journal expurgé de tout jeton ou renseignement personnel.
