# CyEngineHub 0.1.0-alpha.4

## Corrections

- Ajout du logo CyEngineHub dans l'exécutable Windows : il remplace l'icône
  générique dans l'Explorateur et les raccourcis du bureau et du menu Démarrer.
- Ajout de l'icône à l'installateur Windows.
- Icône multi-résolution adaptée aux différentes tailles d'affichage Windows.

## Mise à jour

Depuis CyEngineHub : **Paramètres → Avancé → Mises à jour**. Activez
**Inclure les préversions Alpha / Bêta**, recherchez les mises à jour, puis
choisissez **Télécharger et installer**.

Vous pouvez aussi utiliser l'installateur Windows ci-dessous ou extraire le ZIP
dans un nouveau dossier. Le runtime .NET est inclus.

**Version Alpha : certaines fonctionnalités restent incomplètes ou instables.
Sauvegardez vos projets avant de les modifier avec le hub.**
