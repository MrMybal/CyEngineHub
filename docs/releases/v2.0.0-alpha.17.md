# CyEngineHub V2 — alpha.17

- Nouvel onglet principal Outils, avec sélection visible dans la navigation.
- Vue Unreal par moteur : prérequis x64, Unreal Version Selector, Unreal Insights et Swarm Agent détectés dans les emplacements connus.
- Prise en charge du sélecteur fourni par le Launcher, y compris les installations personnalisées détectées.
- Lancement des utilitaires après confirmation de leur rôle et de leur chemin, sans arguments d’installation ou d’enregistrement silencieux.
- Vue Toolchains / SDK compacte : recherche, colonnes triables et détails des installations .NET, C++, Windows SDK, Android et Linux détectées.
- Accès conservé au diagnostic de compatibilité par moteur, aux appareils ADB/Quest et aux variables d’environnement.
- Liens vers les ressources officielles Unreal et Microsoft, sans installation automatique.

Cette version inclut également les corrections de téléchargement et du journal de l’alpha.16.
