# CyEngineHub V2 — alpha.16

## Téléchargements

- Correction des échecs Unreal causés par un écart de quatre octets entre la taille du manifeste et un chunk servi avec un en-tête plus récent.
- Reprise des caches concernés sans retélécharger les chunks déjà validés ; les transferts tronqués restent rejetés.
- Fab utilise le téléchargement parallèle des chunks, les nouvelles tentatives réseau et la validation du cache.
- Megascans télécharge plusieurs fichiers signés simultanément et peut segmenter les gros fichiers lorsque le serveur le permet, avec repli sur un flux unique sinon.
- Nouveau réglage indépendant de 1 à 32 connexions par téléchargement Fab/Megascans, 12 par défaut, dans Paramètres → Téléchargements.
- Les octets réutilisés du cache Fab ne gonflent plus le débit réseau affiché.

## Journal

- Vue par défaut centrée sur les événements importants : débuts, fins, annulations, avertissements et erreurs.
- Option Journal complet pour consulter les progressions et diagnostics techniques.
- Recherche adaptée au mode affiché ; détails conservés sur disque.
- Les progressions techniques ne remplacent plus le dernier événement important dans la barre d’état.
