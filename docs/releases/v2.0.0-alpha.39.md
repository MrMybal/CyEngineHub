# CyEngineHub 2.0.0-alpha.39 — KitBash3D / Cargo

Build local Windows, non publié sur GitHub.

- Connecteur intégré Alpha non officiel **KitBash3D · Cargo**, source Bibliothèque et sous-onglet Marketplace dédiés.
- My Assets officiel dans le navigateur intégré, session isolée, destination des téléchargements configurable. Aucun statut de connexion inventé ni lecture de cookies.
- Kits locaux ZIP ou dossiers complets (chemin manuel et sélecteur Windows). Copie de l’arborescence et des dépendances sans modifier les originaux.
- Packages JSON, compression commune à Cosmos/Fab et bibliothèques ordonnées avec quotas. Actualisation des packages pour chaque connecteur, sans les mélanger.
- Depuis une fiche : configuration des scripts sur la variante locale exacte, choix du projet et confirmation avant installation. Aucun téléchargement implicite.
- USD classé RAW ; import USD et protocole d’intégration Cargo laissés au connecteur officiel. L’import RAW FBX/OBJ du hub garde son intitulé historique « Importer Megascans ».
- Nettoyage des assemblages temporaires du hub à la fin des imports, même en cas d’échec/annulation.

Validation : 879 tests de solution réussis ; scénario graphique Windows KitBash3D avec réglages, kit local, sélecteur simulé, fiche, scripts et véritable import transactionnel sur projet fictif. La connexion à un compte sous licence et les transferts officiels n’ont pas été validés avec un compte utilisateur.

Le build conserve la migration CyUI alpha.38 et les versions antérieures du plugin Unreal. Aucun asset ni binaire propriétaire KitBash3D n’est inclus.

Voir [le guide des connecteurs](../marketplace-connectors.md) et [la migration CyUI](../cyui-migration.md).
