# CyEngineHub 0.1.0-alpha.1

Première Alpha publique Windows x64.

## Inclus

- Gestion locale des moteurs et projets, outils Unreal de build et de packaging.
- Bibliothèques Fab / Megascans historique : cache, miniatures asynchrones,
  virtualisation, recherche, filtres et téléchargements des formats disponibles.
- Collections, stockage multi-dossiers, compression ZIP par marketplace et scripts d'installation.
- Création de projets Unreal Blueprint/C++, profils et packs de fonctionnalités éditables,
  sélection des plugins et aperçu/modification des INI.
- Éditeur de profils utilisable sans ouvrir le popup de création de projet.
- Extensions de transfert d'assets, déplacement de packs Unreal et conversion expérimentale.
- Tray Windows, démarrage optionnel avec Windows, mise à jour GitHub avec vérification SHA-256.

## Installation

Utilisez `CyEngineHub-0.1.0-alpha.1-Setup-win-x64.exe`, ou extrayez entièrement le ZIP
puis lancez `CyEngineHub.Desktop.exe`. Le runtime .NET est fourni.
Les empreintes sont disponibles dans `SHA256SUMS.txt`.

## À savoir avant de tester

- Alpha en développement : sauvegardez vos projets avant les installations/conversions.
- Binaires non signés Authenticode : un avertissement Windows est possible.
- Les connecteurs Fab/Quixel communautaires peuvent évoluer ; un compte autorisé est requis.
- Unity Asset Store n'a pas encore de connecteur distant complet.
- La conversion Unreal entre versions reste limitée aux types pris en charge ; ce n'est
  pas une conversion universelle de tous les Blueprints, plugins ou matériaux.
- L'installateur conserve les données locales ; aucun moteur ni asset tiers n'est distribué.

Pour signaler un problème, créez une issue avec la version du hub, les étapes et un
log expurgé de tout jeton ou information personnelle.
