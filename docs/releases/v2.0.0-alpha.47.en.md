# CyEngineHub 2.0.0-alpha.47

[Français](v2.0.0-alpha.47.md) · [Windows downloads](https://github.com/MrMybal/CyEngineHub/releases/tag/v2.0.0-alpha.47)

## Local MCP access profiles

CyEngineHub uses CyMCPSDK 0.7.1, built from revision `34d4bcae126bc83d1a2925b5047dac36e3d09d92`. Enable MCP in **Settings → AI / MCP** to open `http://127.0.0.1:47842/mcp`. The port is configurable.

| Profile | HTTP connection | Exposed operations |
| --- | --- | --- |
| Free (default) | URL only | Direct execution |
| Local controlled | URL only | Hub permissions and confirmations |
| Token only | URL and Bearer token | Direct execution |
| Protected | URL and Bearer token | Hub permissions and confirmations |

After upgrading, existing settings without an explicit profile use Free whenever MCP is active. Any local process can connect to a tokenless profile. Saved profile choices and existing limits are preserved. All profiles validate arguments and targets.

Chat and the CLI use the same business operations. Stdio clients can connect in Free and Local controlled. The CLI now accepts `--url` and `--token-env` for HTTP transport. [MCP setup and commands](../ai-mcp.md)
