# CyEngineHub 2.0.0-alpha.44 — Manuel intégré bilingue

Build locale ; cette note ne signifie pas qu'une release GitHub est publiée.

- Centre d'aide dans l'application, accessible par la barre latérale ou F1.
  Retour à la fiche ouverte, sans modifier le projet ou produit sélectionné.
- 25 chapitres en anglais et leurs 25 équivalents français : démarrage,
  navigation, moteurs, patchs, Git, projets, profils, builds/toolchains,
  bibliothèque, Fab, Megascans, connecteurs, transferts, installation,
  conversions/dérivés, plugins, éditeur Unreal, SDK, IA/MCP, stockage,
  paramètres, mises à jour du hub, dépannage et glossaire/licences.
- Anglais par défaut, langue d'aide mémorisée séparément de l'interface générale.
  La traduction partielle de l'application n'est pas présentée comme complète.
- Sommaire groupé, recherche locale tous mots/casse/accents, historique
  précédent/suivant, articles liés, captures agrandissables et schémas natifs.
- Textes et images embarqués dans l'assembly, lisibles sans compte, réseau,
  serveur web, runtime navigateur ou fichiers d'aide à télécharger.
- Illustrations réelles sur données fictives, limites Alpha et procédures de
  confidentialité explicites ; aucun contenu marketplace propriétaire ajouté.
- Contrat natif applicatif ABI 2 pour la hauteur mesurée des documents CyUI,
  avec rejet d'une ancienne DLL incompatible. Dépendances amont inchangées.

Le correctif de patch moteur par plages de l'alpha.43 reste inclus. Aucun essai
de documentation ne lance une mise à jour ou une écriture dans un moteur réel.
