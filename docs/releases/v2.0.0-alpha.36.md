# CyEngineHub 2.0.0-alpha.36

Build local Windows, non publié sur GitHub.

- La fenêtre d’installation Fab propose une case « Forcer l’installation avec
  la méthode choisie (ignorer les refus du Hub) » et le bouton « Installer quand même ».
- Ce choix contourne les refus préalables du Hub : versions, plateformes et types
  déclarés, marketplace désactivée et opérations déjà en cours. La méthode choisie
  est exécutée sans substitution automatique, avec ses options figées au clic.
- Les nouvelles installations restent disponibles pendant une actualisation ou
  une installation ; elles rejoignent la file Actions. Une erreur d’exécution est
  affichée dans la fenêtre et permet de réessayer.
- La case et les boutons restent visibles dans un pied de fenêtre fixe. Les
  variantes et projets défilent au-dessus, y compris sur une petite fenêtre.
- La méthode choisie reste sélectionnée en rouvrant la fenêtre. Le retour aux
  assets conserve la recherche et la page du catalogue.

Forcer lance réellement le script choisi ; cela ne garantit pas qu’un moteur
ancien saura charger les fichiers ni qu’une conversion aboutira. Les contrôles
stricts du plugin éditeur Unreal restent indépendants de cette option manuelle.
