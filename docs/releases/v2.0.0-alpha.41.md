# CyEngineHub 2.0.0-alpha.41 — Convertisseurs de packs

Build local Windows, non publié sur GitHub.

- Plugin intégré **Convertisseurs de packs · Alpha**. Les convertisseurs sont choisis selon les formats du package, pas selon son marketplace.
- Blender installé : scènes `.blend`, USD et formats d’échange → GLB ou FBX, avec options d’animation, sélection des fichiers et accord explicite sur les pertes signalées.
- Importeur générique Unreal RAW : formats d’échange, textures et sons → UAssets sérialisés avec le moteur cible, hors projet utilisateur, avant installation transactionnelle.
- **Convertir en dérivé local…** depuis les fiches de connecteur : GLB/FBX ou package UAsset, compression/quota/bibliothèque du market et lien vers l’original. Nom distinct, formats réels et version cible conservés. Aucun changement des originaux.
- Configuration d’installation : chaîne suggérée Blender → RAW Unreal pour un `.blend`, RAW Unreal pour les formats interopérables ; options modifiables par pack, projection du type de sortie entre les étapes et nettoyage des espaces temporaires.
- SDK C# `IAssetSourceConverter`, registre et contrat `IFabPreparationScript`. Les scripts externes déclarant `preparedContentKind` reçoivent `OutputDirectory` / `ResultFile` pour fournir une sortie contrôlée à l’étape suivante.

Validation réelle : Blender 3.6 et 5.2 exportent/rechargent GLB et FBX sur fixtures avec géométrie, UV, matériau texturé, animation et morph ; USD exporté puis reconverti. Unreal 5.5 produit six assets et un nouveau processus recharge géométrie, animation et matériau référant la texture. Les originaux restent identiques ; le script autoexec embarqué ne s’exécute pas. Le parcours graphique crée et indexe un dérivé GLB, conserve son lignage et nettoie ses temporaires.

Limites : pas de convertisseur universel pour shaders procéduraux, Geometry Nodes, contraintes, `.max`/CAD ou plug-ins DCC propriétaires. Aucune équivalence visuelle universelle. Les pertes détectées sont refusées sans accord explicite ; les outils propriétaires supplémentaires passent par le SDK et ne sont pas déclarés testés. Autres moteurs/versions et assets commerciaux réels non validés par les fixtures.

Voir [options, sécurité, SDK et périmètre](../source-converters.md). Les limites de synchronisation des marketplaces de l’alpha.40 restent inchangées.
