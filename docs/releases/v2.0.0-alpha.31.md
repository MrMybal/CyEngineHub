# CyEngineHub — alpha.31 locale

## Paramètres des marketplaces

- Cosmos reprend la présentation Fab/Megascans : carte de configuration, compression
  à droite, champ de téléchargement aligné et bibliothèques ordonnées avec numéro,
  quota et actions de réorganisation.
- Les profils ZIP utilisent les mêmes libellés et descriptions : Stockage, Rapide,
  Moyen, Élevé et Ultra. Cosmos conserve aussi son mode Non compressé. Les valeurs
  enregistrées restent compatibles avec les paramètres existants.
- Les actions Enregistrer et Ouvrir l’inventaire sont regroupées sous la carte ;
  le bouton d’enregistrement et les indications de sauvegarde sont communs aux
  autres marketplaces.
- Les téléchargements Cosmos restent gérés par le navigateur intégré : aucun
  réglage de connexions Fab/Megascans ne lui est appliqué artificiellement.

Les chemins, quotas, compression et priorités gardent leur sauvegarde automatique.
Cette modification d’interface ne déplace ni ne recrée les fichiers existants.

Build local intermédiaire ; changements inclus dans la release alpha.32.
