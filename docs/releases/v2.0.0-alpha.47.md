## Profils MCP locaux

CyEngineHub utilise CyMCPSDK 0.7.1, compilé à la révision `34d4bcae126bc83d1a2925b5047dac36e3d09d92`. Activez MCP dans **Paramètres → IA / MCP** pour ouvrir `http://127.0.0.1:47842/mcp`. Le port est configurable.

| Profil | Connexion HTTP | Opérations exposées |
| --- | --- | --- |
| Free (par défaut) | Adresse seule | Exécution directe |
| Local contrôlé | Adresse seule | Permissions et confirmations du hub |
| Jeton seul | Adresse et jeton Bearer | Exécution directe |
| Protégé | Adresse et jeton Bearer | Permissions et confirmations du hub |

Après mise à jour, les anciens réglages sans profil explicite utilisent Free dès que MCP est actif. Tout processus local peut utiliser les profils sans jeton. Les choix enregistrés et les limites existantes sont repris. Tous les profils valident les arguments et les cibles.

Le chat et le CLI utilisent les mêmes opérations métier. Les clients stdio peuvent se connecter en Free et en Local contrôlé. Le CLI accepte désormais `--url` et `--token-env` pour le transport HTTP. [Configuration et commandes MCP](../ai-mcp.md)
