# CyEngineHub V2 — alpha.32

Cette version conserve l’interface officielle V2. Les extensions et la conversion
d’assets restent Alpha : sauvegardez vos projets avant installation ou conversion.

## Paramètres Cosmos

- Présentation harmonisée avec Fab/Megascans : compression, dossiers et bibliothèques
  ordonnées avec numéro, quota et actions alignées.
- Libellés de compression communs, sauvegarde compatible et actions regroupées sous
  la carte. Les fichiers existants ne sont ni déplacés ni recréés par ce changement.

## Conversion Unreal avec agent optionnel

- Unreal Version Bridge 0.5.0-alpha : assistance IA / MCP optionnelle via le vrai
  wheel MIT CyToolsCore 0.10.1 et le transport MCP Python 1.30.0.
- Si le bridge natif bloque, préparation d'une copie de réparation, de diagnostics
  et d'un `mcp.json`. Aucun fournisseur choisi, agent lancé ou asset envoyé par le hub.
- Consentements séparés pour l'assistance et l'exécution Python/C++/Build.cs.
  Ces programmes disposent des droits du compte OS ; ce n'est pas un bac à sable.
- SDK : inspection paginée, scripts source/cible, adaptation de source plugin,
  compilation dans le moteur cible, validation et réouverture cible fraîche.
- Reprise explicite depuis le hub, inventaire comparé au pack original,
  revalidation indépendante avant publication d'un dérivé ou installation.
- Installation des plugins dans Projet/Plugins avec leur point de montage ;
  pas d'injection de leur Content à la racine du projet.
- Les tâches IA en attente ne sont pas comptées comme installations terminées
  et suspendent les étapes suivantes d'un groupe.
- Paramètres IA regroupés dans une section repliable pour conserver le formulaire
  de conversion compact. Installation Python seulement sur demande explicite.

Limites : un plugin racine par tâche, sources obligatoires pour les modules C++,
build Win64. Aucun downgrade universel ni équivalence visuelle/comportementale
garantis. L'agent reste un recours, pas une preuve de conversion réussie.

Guide détaillé : `extensions/builtin/cyenginehub.unreal-version-bridge/mcp/README.md`.

Validation locale : 729 tests .NET réussis (12 projets), interface ImGui testée,
vrai client MCP avec le wheel MIT installé, annulation du worker et de ses
descendants. Fixture Blueprint Actor vide UE 5.7 → 5.5 reconstruite, compilée,
sauvegardée et réouverte. Plugin C++ de test compilé et rechargé sous UE 5.5.
Ces fixtures valident le parcours SDK, pas la conversion universelle d'un pack.
L'assistance MCP n'a pas été validée sur UE 5.3 ni sur d'autres plateformes.

## Installation

Windows x64 : installateur, ZIP autonome et SHA256SUMS.txt. Terminez les opérations
en cours avant mise à jour. Les deux distributions conservent les données utilisateur
existantes ; le ZIP n’active pas automatiquement le mode portable.

La version est affichée comme Release courante sur GitHub pour être visible dans
le panneau Releases. L’appellation Alpha et les limites fonctionnelles restent
inchangées ; le badge Latest n’est pas une garantie de stabilité.
