# CyEngineHub 2.0.0-alpha.26 — extensions et groupes de packs

Version locale de test ; aucune publication GitHub automatique.

- Les extensions sont affichées Alpha. Les fonctions expérimentales se testent sur des copies.
- Bibliothèque : gestionnaire de groupes de packs locaux, variantes précises, ordre des packs et plusieurs scripts configurables par pack. Installation de tout un groupe dans un projet Unreal sélectionné depuis un bouton unique.
- Les étapes de conversion et déplacement préparent leur sortie isolée avant l’installation finale. Les scripts externes choisis explicitement reçoivent une copie matérialisée, jamais le pack original.
- Échec ou annulation : arrêt de la chaîne, nombre de packs terminés affiché. Les packs déjà installés restent en place ; pas de rollback global automatique du groupe. Les conflits sont refusés par défaut dans les nouveaux groupes ; le remplacement avec sauvegarde peut être choisi explicitement.
- Cosmos : destination par projet sous `/Game`, packages `cyenginehub-package.json`, compression configurable, bibliothèques ordonnées avec quotas et réindexation des manifests locaux. Les originaux téléchargés/importés sont conservés. L’ouverture répétée d’une fiche ne crée plus de package supplémentaire pendant la session.

## Résultats et limites

Le test réel du pack possédé « Foliage VOL.3 – Oak Trees », copié puis réenregistré avec Unreal 5.7, ne valide **pas** un downgrade complet vers 5.5 ou 5.3 : le bridge ne dispose pas des profils/adaptateurs requis. Il bloque avant installation et conserve les diagnostics et originaux. La liste des versions compatibles d’un produit ne prouve pas sa version réelle de sauvegarde.

Le déplacement de packs contenant des niveaux `.umap` n’est pas pris en charge : refus du pack entier, aucune publication partielle. Le déplacement d’un graphe de test sans niveaux a été exécuté dans Unreal 5.7 ; après installation et réouverture dans un nouveau processus, l’instance de matériau référence bien son parent déplacé et les anciens chemins ne sont plus présents.

La chaîne d’import d’une texture source TGA puis déplacement vers `/Game/CosmosQA` a aussi été exécutée dans Unreal 5.5.4. Une réouverture indépendante retrouve une `Texture2D` au nouvel emplacement et aucun asset à l’ancien chemin. Ce test ne valide pas tous les formats RAW ni les packs Cosmos complexes.

Les téléchargements Cosmos sont testés avec des réponses WebView locales simulées, sans lire de session ni contacter un compte réel. Les groupes sont testés avec l’importeur transactionnel réel sur des projets fictifs ; les fixtures `.uasset` de ces tests d’interface ne constituent pas une preuve de compatibilité Unreal.
