# CyEngineHub V2 — alpha.30

This preview includes the changes developed since alpha.25. Dear ImGui remains
the official interface. Extensions and asset conversion remain **Alpha**: back up
your projects before installing, converting or moving content.

## Library and installation workflows

- Organize local pack variants into reusable groups and install a group into a
  selected Unreal project from one action.
- Configure an ordered chain of installation scripts per pack, including native
  conversion, relocation and explicitly selected external scripts. Preparation
  takes place on isolated copies rather than the original pack.
- Optionally register a validated converted pack as a derived variant for later
  installation from its product page.
- Cosmos supports per-project destinations under `/Game`, package JSON manifests,
  compression and ordered library folders with quotas.

## Settings and engine management

- Separate connection tabs for Epic, Fab, Git, Megascans and Unity. Enabling a
  service does not mean it is authenticated; Git status is explicitly unverified
  until checked.
- Separate marketplace panels and independent Fab/Megascans connection limits.
- Group Unreal-specific profiles and download settings. Project profile contents
  can be inspected, copied and edited; built-in profiles remain templates.
- Add Grey, Dark and Contrast themes; remove the duplicate Storage settings page.
- Align display modes and the favorites button in Engines and Projects.
- Rename an engine in the catalog, edit its Unreal association from the details
  page, and inspect a source engine's Git branch and upstream status without
  automatically switching branches or updating the checkout.

## Native Unreal conversion

The native bridge exports loaded objects from the source engine and reconstructs
and saves packages with the target engine. Validation requires reopening the
result in a separate target process before publishing the derived variant.

The complete 54-asset Foliage test pack was validated from **5.7.4 to 5.5.4 and
5.3.2**, including textures/HDR, materials and functions, static meshes with LODs,
Nanite reconstruction and two levels. Originals remained unchanged. See the
[native validation report](../native-57-bridge-validation.md) for exact checks and
the supported adaptations.

This is not universal Unreal backward compatibility. Arbitrary gameplay
Blueprints, skeletal meshes/animations, World Partition and streaming levels are
not qualified by these scenarios. Unsupported non-default data blocks conversion;
no header-only version substitution is used. Relocation of packs containing
`.umap` levels remains blocked.

## Installation

Windows x64: installer, standalone ZIP and SHA256SUMS. Finish active operations
before closing the hub to update. Both distributions use the existing per-user
data directory unless portable mode was explicitly enabled. Enable prereleases
in the update settings to receive this alpha.
