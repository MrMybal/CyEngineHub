# v2.0.0-alpha.27 — build local

## Paramètres et profils

- Sous-onglets Epic, Fab, Git, Megascans et Unity, y compris pour réactiver un service désactivé. Une seule configuration visible à la fois ; l'activation d'un service n'est jamais assimilée à une authentification.
- Git apparaît dans le bandeau. Statut distant « non vérifié », sans faux voyant vert fondé sur la présence de dépôts locaux. La gestion des identifiants reste déléguée à Git Credential Manager / SSH ; aucun test réseau ni login n'est lancé implicitement.
- Paramètres Unreal regroupés : profils de projet (plugins et valeurs INI consultables, personnalisation des modèles intégrés, modification des profils utilisateur) et connexions de téléchargement des moteurs.
- Une page de configuration par marketplace et par connecteur. Les boutons Fab/Megascans/Unity n'enregistrent que leur marketplace ; les chemins et bibliothèques gardent leur sauvegarde automatique existante.
- Connexions simultanées Fab et Megascans réglables séparément (1–32). Migration des anciens paramètres partagés conservée. La limite de packs simultanés et la reprise restent globales dans Téléchargements.
- Suppression du doublon Stockage dans Paramètres, sans retirer la page principale Stockage.
- Apparence : thèmes Gris, Sombre et Contraste, aperçu immédiat, enregistrement pour le lancement suivant. La densité est au même endroit.

## Dérivés des conversions

Le script Unreal Version Bridge propose « Ajouter le downgrade aux dérivés du pack », activé par défaut. Une conversion validée peut ainsi être enregistrée dans la fiche du pack pour réinstallation, y compris dans les chaînes de groupes. Désactiver cette case n'efface aucun dérivé existant : la sortie technique reste dans le dossier des variantes mais n'est pas ajoutée à la fiche. Les originaux sont conservés.

Les options des scripts sont réorganisées pour lire les descriptions sur toute la largeur. L'ajout de cette option n'étend pas les capacités de conversion natives : les limites du bridge [restent documentées](../native-57-bridge-validation.md).
