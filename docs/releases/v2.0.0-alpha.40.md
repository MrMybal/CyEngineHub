# CyEngineHub 2.0.0-alpha.40 — Plugins marketplaces

Build local Windows, non publié sur GitHub.

- Cinq plugins Alpha : **itch.io**, **BlenderKit / Blendkit** (un seul service), **ArtStation**, **Gumroad**, **CGTrader**.
- Sources Bibliothèque et sous-onglets Marketplaces dédiés, avec activation, téléchargements et paramètres de stockage indépendants.
- Même système de packages locaux que Cargo : JSON, compression, emplacements ordonnés/quotas, ZIP/dossiers complets, fiches et scripts d’installation configurables avant confirmation. Aucun achat, reçu, clé ou cookie aspiré automatiquement.
- Capacités de packaging et libellés déclarés par le manifeste, sans liste de nouveaux noms codée en dur dans le moteur d’import.
- Protection contre les compatibilités fictives : fichiers Blender/DCC, PDF et exécutables ne sont pas déclarés packs Unreal. Les fichiers de type inconnu restent disponibles à la configuration mais sans script présélectionné. Aucun fichier reçu n’est exécuté automatiquement.
- BlenderKit/Blendkit utilise le point d’entrée officiel actuel. Les imports dépendant de son add-on officiel sont ensuite ajoutables localement ; pas de conversion `.blend` automatique.

**Limite explicite :** ces connecteurs livrent l’accès web officiel et la gestion locale, pas la synchronisation d’inventaire par API/OAuth. Les API itch.io et Blendkit ne sont pas utilisées dans cette version ; les comptes et téléchargements sous licence réels restent à valider avec leur propriétaire.

Tests : suite automatisée complète et scénario graphique des cinq plateformes, sessions/destinations isolées, réglages persistants, enregistrement des fichiers et import transactionnel sur projet fictif. Retour aux assets et onglets testés à 1280/1024 px. Les originalités/limitations de chaque plateforme sont décrites dans le [guide des connecteurs](../marketplace-connectors.md).

Conserve CyUI alpha.38 et le connecteur KitBash3D/Cargo alpha.39. Aucun asset ou client propriétaire tiers n’est embarqué.
