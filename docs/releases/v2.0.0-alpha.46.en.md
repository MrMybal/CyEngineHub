# CyEngineHub 2.0.0-alpha.46

[Français](v2.0.0-alpha.46.md) · [Windows downloads](https://github.com/MrMybal/CyEngineHub/releases/tag/v2.0.0-alpha.46)

## Assistant and MCP commands

- Open the built-in assistant in **Settings → AI / MCP**. It streams responses and supports cancellation, attachments, and history restoration. You can limit how much conversation context the provider receives.
- Chat, the CLI, and external MCP clients share ten business operations and the hub's confirmation rules. The CLI provides `list`, `describe`, and `call` with JSON output. Chat can also call explicitly allowed tools from an HTTP(S) MCP server.
- The Unreal repair companion uses CyMCPSDK 0.7.0 at revision `ced8296b555c1969cb29740eba65beaa0687da7d`. Existing repair workspaces, jobs, and historical results remain usable. [MCP setup, commands, and scope](../ai-mcp.md)

## Library and Unreal projects

- The Fab product page shows separate transfer, reconstruction, archiving, and storage stages. Reconstruction reuses decoded blocks and checks file integrity while writing.
- Cross-drive transfers publish the complete package before cleaning up the source. Safe Clean and ZIP creation check Windows junctions. Local imports keep their package after temporary files are cleaned up.
- Generated C++ project rules adapt to the Unreal version. Plugin installation preserves third-party runtime libraries, and discovery skips plugin backups.

This release provides Windows x64 binaries. Precompiled editor plugins are available from the [alpha.45 release](https://github.com/MrMybal/CyEngineHub/releases/tag/v2.0.0-alpha.45). Compatibility depends on the exact Unreal build.
