# CyEngineHub 2.0.0-alpha.19

Version locale, non publiée.

- Actions contextuelles sur les prérequis manquants ou à vérifier : version requise,
  composant détecté, consignes et téléchargements officiels accessibles dans Outils.
  Aucune installation ou exécution automatique ; le téléchargement se poursuit dans
  le navigateur sur le site du fournisseur. Gradle est réparé avec le moteur.
- Détection des wrappers Gradle dans les deux dispositions Unreal et du runtime
  .NET dans les anciens dossiers `windows` ainsi que `win-x64`. Un runtime embarqué
  d’un autre moteur ne valide plus le moteur sélectionné.
- Inventaire des toolchains Linux du dossier standard Windows et des racines
  versionnées fournies par l’environnement ; les dossiers sans compilateur sont ignorés.
  Lecture de la version Linux requise par les anciens moteurs, notamment UE 5.2.
- Boutons de lancement/compilation verts, retrait/désinstallation rouges dans leurs
  états normal, survolé et pressé, actions principales bleues et sections dépliables neutres.
- Réanalyse manuelle commune à l’inventaire et aux diagnostics ; l’aide se ferme
  lorsque le prérequis est prêt après une nouvelle analyse.
