# CyEngineHub 2.0.0-alpha.45 — CyDoc documentation and fixes

**English** · [Français](v2.0.0-alpha.45.md) · [Release and downloads](https://github.com/MrMybal/CyEngineHub/releases/tag/v2.0.0-alpha.45)

**Stage: Alpha**, an experimental release for testing and feedback.

## Changes

- Updated CyDoc reader, integrated with Help/F1 and the public documentation.
- 25 complete user chapters in English and French, plus four API contract/import references; no source implementation listings in the human reader.
- Nested navigation, global search/Ctrl+K, full-title tooltips, themes, remembered reading positions, screenshots and a local gallery.
- The manual opens directly through `Documentation/Documentation.html`, without a server, CDN or account. Scripts, styles and media remain in `DocData`; `DocAI.md` stays outside human navigation and search.
- Shared generation and packaging for the application and GitHub Pages. Histories, audits and maintenance instructions are no longer manual pages.
- Engine-patch fix: prepare changed byte ranges and their rollback data, without a second complete copy of changed files. Integrity verification, exclusive locks and a durable journal; temporary space is calculated separately from network transfer and final size.
- Native CyUI ABI 2 contract and natural product-description height.

Engine patches were tested on synthetic installations only. No update or modification was executed against real Unreal installations during these checks.

The manual language remains independent of the partially translated application UI. User data, accounts, projects, engines and downloads are preserved. Alpha limitations documented in the manual still apply.

## Known limitations and issue tracking

- Published builds target Windows 10/11 x64; these notes do not announce Linux or macOS distributions.
- Conversions and connectors remain partial: no universal Unreal downgrade, automatic retargeting of binary-only plugins or complete inventory API for every marketplace.
- The French manual is complete; the application UI remains partially translated. The Windows embedded reader uses the separately installed WebView2 Runtime.
- Byte-range engine-patch tests are synthetic, not validation of a real commercial UE 5.8 patch.

These notes do not publish a ticket-by-ticket bug list. This does not imply there are no bugs: consult the [issue tracker](https://github.com/MrMybal/CyEngineHub/issues) and the detailed limitations in the [English manual](https://mrmybal.github.io/CyEngineHub/Documentation.html#/en/welcome).
