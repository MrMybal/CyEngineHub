# CyEngineHub Layout Studio

Outil autonome de maquettage destiné à préparer les futures modifications de l’interface CyEngineHub. Il ne modifie pas l’application principale.

## Utilisation

1. Ouvrir start-layout-studio.cmd ou index.html.
2. Choisir une page dans la colonne de gauche.
3. Déplacer les blocs à la souris et utiliser leur coin inférieur droit pour les redimensionner.
4. Ajouter des annotations jaunes ou sélectionner un élément puis remplir « Instruction pour Codex ».
5. Cliquer sur « Copier le brief » pour envoyer les demandes sous forme de texte, ou « Exporter JSON » pour conserver et partager toute la maquette.

Les modifications sont sauvegardées automatiquement dans le stockage local du navigateur. Les exemples couvrent moteurs, projets, bibliothèque, plugins, extensions, paramètres et logs RAW.
